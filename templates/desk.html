Only for you. Write a dispatch and hit Publish, or save it as a draft to finish later. Each one is still filed as its own pull request behind the scenes. Readers see it on the site a few minutes after you publish. Write your dispatch and hit Send to the editor. One-time setup on this device: connect your GitHub account
  1. Open GitHub → new fine-grained token.
  2. Name it "Hardwood Bricks desk". Repository access: Only select repositories → {{ notes_repo }}.
  3. Permissions → Repository: Contents: Read and write and Pull requests: Read and write. Generate, then paste it here.
The token stays in this browser only. It is never sent anywhere except GitHub, and never saved in the site or the repo.
