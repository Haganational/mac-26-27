Free account, no paid tier

  1. Go to x.com/i/flow/signup, sign up with an email, and verify the code. Skip every Premium or Verified prompt; nothing here needs it.
  2. Pick a handle and skip the "follow suggestions" step (or follow @MACSports there).
  3. Work down this page: each handle opens the profile in a new tab, press Follow, come back and tick the box.
  4. Optional: make a private List per team (Profile → Lists → New List) and add the same accounts, so each team gets its own clean timeline.
  5. For players with no handle listed, the "find" link runs an X people search (works once you're signed in). Match the bio to the school before following.

The free tier can read and follow normally in the app. Its API can't read timelines, so posts aren't pulled into this dashboard.
