# Courtside reviews

One file per night (`YYYY-MM-DD.json`, Eastern date), written by the Courtside desk
(`courtside-desk.html`). The anchors' drafts live in `data/anchors/nights/`; nothing they
write shows on the site until its id is listed under `approve` here.

```json
{
  "approve": ["sully-pre", "ivy-pre"],
  "hold": ["dee-pre"],
  "edit": {"ivy-pre": "Replacement text for that take."},
  "matthew": [{"id": "m-1731470000", "at": "2026-11-13T23:40:00Z", "text": "Your own comment, shown with a human badge."}]
}
```
